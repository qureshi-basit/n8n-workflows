## Use one

1. Open a file in `workflows/` and copy the JSON (or download it).
2. In n8n: **Workflows → Import from File** (or paste onto the canvas).
3. Follow the yellow overview note on the canvas for setup.

Credentials are never included. Every workflow lists what you need to connect in its overview note.
